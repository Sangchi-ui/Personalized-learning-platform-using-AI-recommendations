# VibeLearn: Antigravity OS
*From Mockup to Functional Neuro-Adaptive Learning Engine.*

## 🚀 Where We Are (Current State)
We have successfully transformed the initial concept into a fully functional **"Antigravity"** learning system designed to combat low attention spans and dopamine addiction.

### Key Features Implemented:
*   **Antigravity Learning Engine**: A dynamic focus system that detects "High Entropy" behavior (e.g., rapid mouse movement/fidgeting) and automatically triggers a "Re-calibration".
    *   *Effect*: If you lose focus, the system catches you and instantly adjusts the curriculum to shorter, more manageable "Micro-tasks" (e.g., reducing focus blocks from 15m to 5m).
*   **Reward Mode** (Formerly Entertainment Mode): A strategic dopamine release system.
    *   Integrates a dedicated "Dopamine Overlay" that unlocks only during earned breaks.
    *   **Strict Content Filtering**: We successfully blocked "Shorts" & "Reels" during Deep Work sessions by enforcing a minimum 4-minute video duration via the YouTube API.
*   **Contextual Verification**:
    *   Replaced generic quizzes with a **Domain-Specific Logic Engine**.
    *   If you study *Finance*, you get Finance questions. If *Design*, Design questions.
    *   Includes a **"Speedrun Detector"** to prevent verify-skipping (<50% watch time triggers Hard Mode).
*   **True YouTube Operations**:
    *   Full `YouTube IFrame API` integration using secure environment keys (`.env`).
    *   Auto-fallback mechanisms ensuring no "Video Unavailable" black screens.

## 🛠️ Tech Stack
*   **Frontend**: Vite, React (Components), Vanilla JS (Antigravity Engine).
*   **APIs**: YouTube Data API v3 (Embeddable & Duration filtering).
*   **State Management**: LocalStorage + Custom Event Bus.

## ⚡ How to Run
1.  **Install**: `npm install`
2.  **Environment**: Ensure `.env` contains your `VITE_YOUTUBE_API_KEY`.
3.  **Launch**: `npm run dev`
4.  **Experience**:
    *   Navigate to **Find by Describing...** to calibrate.
    *   **Shake your mouse** vigorously during a video to test the Entropy Detector.
